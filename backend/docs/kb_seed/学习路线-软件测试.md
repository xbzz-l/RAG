# 软件测试学习路线

## 路线总览
软件测试负责发现软件缺陷、保障质量。路线以「测试理论 → 测试工具 → 自动化与开发能力」为主线，门槛相对开发低，是转行 IT 的热门入口。总周期约 6-10 个月。

## 阶段一：测试理论与基础（4-6 周）
- **学什么**：软件生命周期与测试流程、测试用例设计方法（等价类/边界值/判定表/场景法/错误推测）、缺陷管理（禅道/Jira）、测试类型（功能/兼容/安全/性能）
- **核心知识点**：测试用例八大要素、用例设计方法实战、Bug 描述规范
- **阶段产出**：为电商登录/购物流程编写完整测试用例集 + 缺陷报告
- **检验标准**：能独立设计覆盖全面的测试用例

## 阶段二：工具与实战（4-6 周）
- **学什么**：接口测试工具 Postman/Apifox、抓包工具 Charles/Fiddler、数据库基础（MySQL 查询验证数据）、Linux 基础命令
- **核心知识点**：HTTP 协议、接口测试流程（参数/断言/鉴权）、抓包分析
- **阶段产出**：对一个真实项目执行一轮完整功能+接口测试并输出报告
- **检验标准**：能独立完成接口测试与抓包定位问题

## 阶段三：自动化测试（8-12 周）
- **学什么**：Python 基础 + Selenium（UI 自动化）+ Pytest（测试框架）+ Requests（接口自动化）+ 数据驱动/PO 设计模式
- **核心知识点**：元素定位、等待机制、断言与报告（Allure）、持续集成（Jenkins 概念）
- **阶段产出**：一套可重复运行的 UI/接口自动化测试脚本
- **检验标准**：测试脚本能在 CI 流水线中自动执行

## 阶段四：性能与专项（4-8 周，按方向选）
- **学什么**：JMeter 性能测试（压测/监控/分析）、安全测试基础、App 测试（adb/兼容性）
- **核心知识点**：性能指标（TPS/响应时间/错误率）、瓶颈定位思路
- **阶段产出**：性能测试报告一份
- **检验标准**：能执行压测并分析瓶颈

## 阶段五：就业与进阶
- **就业方向**：功能测试工程师（入门）、自动化测试工程师、测试开发工程师（薪资上限最高）
- **进阶路线**：测试开发——补开发能力（Java/Python 后端、框架原理），做测试平台/工具开发
- **面试重点**：用例设计方法、Bug 定位思路、自动化框架设计、数据库与 Linux 基础
