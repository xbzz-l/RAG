# MySQL

## 一、是什么
MySQL 是 **全球最流行的开源关系型数据库管理系统（RDBMS）**，由瑞典 MySQL AB 开发，现属 Oracle。定位：以 SQL（结构化查询语言）管理结构化数据，是后端开发必备数据库技能。

## 二、核心知识
- **SQL 基础**：DDL（建表/改表）、DML（增删改）、DQL（查询）、DCL（权限）
- **查询语法**：SELECT/JOIN（内连接/左连接/右连接）/GROUP BY + 聚合函数/HAVING/子查询/UNION/LIMIT
- **索引**：B+ 树索引原理；聚簇索引与非聚簇索引；最左前缀原则；覆盖索引；索引失效场景（函数/隐式类型转换/前导模糊）
- **事务与隔离级别**：ACID（原子性/一致性/隔离性/持久性）；四种隔离级别（读未提交/读已提交/可重复读/串行化）；MVCC 多版本并发控制（undo log + ReadView）
- **锁机制**：行锁/表锁/间隙锁；乐观锁（版本号）与悲观锁（select for update）
- **存储引擎**：InnoDB（默认，支持事务/行锁/外键）与 MyISAM（旧版，无事务）
- **日志体系**：redo log（持久性）、undo log（回滚/MVCC）、binlog（主从复制/恢复）
- **Explain 执行计划**：type/rows/key/Extra 分析慢查询
- **SQL 优化**：避免 SELECT *、合理分页、批量操作、分库分表思路
- **主从复制与高可用**：binlog 同步、读写分离

## 三、作用与常用场景
- 一切需要持久化结构化数据的业务系统（订单、用户、商品）
- 与 Redis 组合：MySQL 存数据，Redis 做缓存
- 报表统计、数据分析源库

## 四、基于什么语言/底层原理
- **开发语言**：C/C++ 编写；通过驱动（JDBC/mysql2 等）供 Java/Python/Node 等语言访问
- **存储原理**：数据以 B+ 树组织在磁盘页（默认 16KB）上；查询经连接器/分析器/优化器/执行器走存储引擎

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 免费开源、社区庞大、资料极多 | 海量数据高并发写入场景需分库分表 |
| 简单易用，ACID 事务可靠 | 复杂全文检索/海量日志分析能力弱于 ES |
| 生态成熟（监控/备份/中间件齐全） | JSON 等非结构化数据支持弱于 MongoDB |
| 与主流后端框架深度集成 | 水平扩展需要额外方案（主从/分片） |
