# 人工智能与机器学习

## 一、是什么
人工智能（AI）是让机器模拟人类智能的学科；**机器学习（ML）**是 AI 的核心子领域——不显式编程规则，而是让算法从数据中学习规律；**深度学习（DL）**是机器学习的分支，用多层神经网络自动提取特征。2022 年底大语言模型（LLM，如 GPT/DeepSeek/Qwen）引爆生成式 AI。

## 二、核心知识
**机器学习基础**
- 三大范式：监督学习（分类/回归，有标签）、无监督学习（聚类/降维，无标签）、强化学习（试错奖励）
- 经典算法：线性回归、逻辑回归、决策树/随机森林、SVM、KNN、K-Means、朴素贝叶斯
- 核心概念：训练集/验证集/测试集、过拟合与欠拟合（正则化）、交叉验证、特征工程
- 评估指标：准确率/精确率/召回率/F1、ROC-AUC、混淆矩阵

**深度学习**
- 神经网络基础：神经元、激活函数（ReLU/Sigmoid）、反向传播、梯度下降
- 主流架构：CNN（图像）、RNN/LSTM（序列）、Transformer（注意力机制，现代基石）、GAN（生成对抗）
- 框架：PyTorch（研究首选，动态图）、TensorFlow（工业部署）

**大模型与生成式 AI（当前热点）**
- LLM 三阶段：预训练（海量语料）→ 监督微调 SFT → 人类反馈强化学习 RLHF
- Prompt 工程、RAG（检索增强生成：外挂知识库回答问题）、Agent（智能体调用工具）、微调（LoRA 低成本）
- 主流模型：DeepSeek、Qwen（通义千问）、GPT、Claude、Llama

## 三、作用与常用场景
- 图像：人脸识别、医学影像、自动驾驶感知
- 自然语言：智能客服、翻译、搜索、代码助手
- 推荐系统、风控反欺诈、销量预测
- 生成式：文案/代码/图像生成（AIGC）

## 四、基于什么语言/底层原理
- **开发语言**：Python 是事实标准（NumPy/pandas 数据处理 + PyTorch 建模）
- **底层原理**：数学三件套——线性代数（矩阵运算）、微积分（梯度优化）、概率统计（数据分布）；GPU 并行加速矩阵运算

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 解决传统规则无法处理的复杂问题 | 依赖大量高质量数据与算力 |
| 行业应用极广，岗位薪资高 | 模型可解释性差（黑盒） |
| 大模型时代门槛下移（调 API 即可用） | 研究门槛高（数学+工程+算力） |
| 自动化程度高，持续学习进化 | 存在幻觉、偏见、隐私风险 |

## 六、学习建议
两条路线：**应用路线**（当前主流）——Python 基础 → 机器学习概念 → 大模型 API 与 Prompt → RAG/Agent 应用开发（LangChain）→ 项目实战；**算法路线**——数学（线代/概率）→ 经典 ML 算法 → PyTorch 深度学习 → 论文复现。
