# Redis

## 一、是什么
Redis（Remote Dictionary Server）是 **基于内存的开源键值（Key-Value）数据库**，由 Salvatore Sanfilippo 开发。定位：高速缓存与数据结构服务器，单机 QPS 可达十万级。

## 二、核心知识
- **五种基础数据类型**：String（字符串/计数器）、Hash（对象属性）、List（列表/消息队列）、Set（集合/去重）、ZSet（有序集合/排行榜）
- **高级数据结构**：Bitmap（签到统计）、HyperLogLog（UV 估算）、Geo（地理位置）、Stream（消息流）
- **持久化**：RDB（快照，二进制）与 AOF（追加写命令日志）；混合持久化
- **过期策略**：惰性删除 + 定期删除；内存淘汰策略（LRU/LFU/allkeys-lru 等 8 种）
- **缓存三大问题**：缓存穿透（空值缓存/布隆过滤器）、缓存击穿（热点 key 互斥锁/逻辑过期）、缓存雪崩（过期时间加随机值）
- **缓存一致性**：Cache Aside 模式（先更新 DB 再删缓存）、延迟双删、canal 订阅 binlog
- **事务与 Lua**：MULTI/EXEC 弱事务；Lua 脚本保证原子性
- **集群**：主从复制（读写分离）、哨兵 Sentinel（高可用自动故障转移）、Cluster 分片集群（16384 槽位）
- **底层实现**：SDS 动态字符串、跳表（ZSet）、压缩列表/quicklist、渐进式 rehash

## 三、作用与常用场景
- 缓存热点数据（数据库前置缓存，最常见）
- 分布式锁（SET NX EX / Redisson）
- 排行榜、计数器、限流、会话存储
- 消息队列（List/Stream，轻量场景）
- 分布式 ID 生成（INCR）

## 四、基于什么语言/底层原理
- **开发语言**：C 编写；RESP 协议通信，各语言有官方/社区客户端
- **高性能原理**：纯内存操作 + 单线程命令执行（避免锁竞争）+ IO 多路复用（epoll）；网络与持久化在独立线程

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 性能极高（内存 + 单线程模型） | 内存成本高，数据量受内存限制 |
| 数据结构丰富，场景覆盖广 | 数据持久化是异步的，极端情况可能丢数据 |
| 集群方案成熟（主从/哨兵/分片） | 不支持 SQL 复杂查询 |
| 使用简单、生态完善 | 单线程大 key 操作会阻塞 |

## 六、学习建议
先掌握五种数据类型与常用命令（菜鸟教程 Redis 教程）→ 持久化与淘汰策略 → 缓存三大问题与一致性方案（面试必问）→ 分布式锁 → 集群搭建；结合 Spring Boot/Express 项目实际集成。
