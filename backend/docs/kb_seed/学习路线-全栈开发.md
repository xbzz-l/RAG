# 全栈开发学习路线

## 路线总览
全栈工程师同时掌握前端与后端，能独立完成完整产品。建议**先深后广**：主攻一条线（前或后），再补齐另一条。总周期约 12-18 个月。

## 阶段一：前端基础（8 周）
- **学什么**：HTML/CSS/JavaScript 三件套 + ES6+ 语法
- **核心知识点**：布局、DOM 操作、事件循环、Promise
- **阶段产出**：静态页面 + 原生 JS 交互应用
- **检验标准**：能独立写页面与基本交互

## 阶段二：后端基础（8 周）
- **学什么**：一门后端语言与框架——推荐 **Node.js + Express**（与前端同语言，全栈学习成本最低）或 Java Spring Boot / Python FastAPI；MySQL 与 SQL
- **核心知识点**：RESTful API 设计、路由与中间件、数据库增删改查、JWT 鉴权
- **阶段产出**：能提供完整接口的 API 服务
- **检验标准**：前端页面能调通自己写的接口

## 阶段三：前后端整合（6-8 周）
- **学什么**：Vue 3 框架 + 组件库、Axios 联调、跨域处理（CORS/代理）、用户认证全流程
- **核心知识点**：组件化、路由守卫、Token 存取与拦截器、项目结构
- **阶段产出**：**第一个全栈项目**——前后端分离的博客/待办/商城系统（登录注册 + CRUD + 数据持久化）
- **检验标准**：一个项目从前端到数据库全部独立完成

## 阶段四：工程化与部署（4-6 周）
- **学什么**：Git 协作、TypeScript、Vite/Webpack、Docker、Linux 服务器部署、Nginx
- **核心知识点**：环境变量管理、构建流程、容器化、反向代理与 HTTPS
- **阶段产出**：把全栈项目部署到服务器/云主机，域名可访问
- **检验标准**：公网能访问自己的项目，能讲清完整请求链路

## 阶段五：进阶与就业（持续）
- **学什么**：Redis 缓存、消息队列、微服务概念、SSR（Nuxt/Next）、小程序/跨端
- **就业方向**：全栈工程师、独立开发者、创业型公司技术负责人
- **面试重点**：完整项目经历（最有说服力）、HTTP 协议、数据库优化、鉴权方案、部署流程
