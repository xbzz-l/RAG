# 游戏开发学习路线

## 路线总览
游戏开发分引擎工具链与底层引擎两个层次。主流路径：**Unity（C#，手游市场主流）+ C# 语言** 或 **Unreal（C++，3A 与高品质画面）**。总周期约 12-18 个月。

## 阶段一：编程语言（8-10 周）
- **学什么**：C#（Unity 路线，推荐新手）——语法、面向对象、委托与事件、泛型、异步；或 C++（Unreal 路线）——指针/内存/STL/面向对象
- **核心知识点**：面向对象设计、数据结构与算法基础（游戏开发高频使用）
- **阶段产出**：控制台小游戏（猜数字/文字冒险/贪吃蛇）
- **检验标准**：语言语法与 OOP 扎实

## 阶段二：引擎入门（10-14 周）
- **学什么（Unity 路线）**：
  - Unity 编辑器与场景系统、游戏对象与组件模型（GameObject/Component）
  - 物理系统（碰撞体/刚体）、脚本生命周期（Awake/Start/Update）、输入系统
  - UI 系统（UGUI）、动画系统（Animator 状态机）、音效
  - C# 脚本编写：移动/跳跃/碰撞响应/计分
- **核心知识点**：组件化架构思想、帧循环与生命周期、预制体 Prefab、场景切换与数据传递
- **阶段产出**：2D 小游戏（如平台跳跃/射击游戏）
- **检验标准**：能独立完成一个可玩的小游戏并打包发布

## 阶段三：进阶能力（8-12 周）
- **学什么**：游戏 AI（寻路 NavMesh/A*、状态机 AI）、对象池与性能优化（DrawCall/内存管理）、存档系统、资源管理（Addressables）、网络基础（联机同步概念）
- **核心知识点**：性能剖析与优化、对象池模式、帧同步/状态同步差异
- **阶段产出**：带敌人 AI、完整关卡与存档的游戏
- **检验标准**：游戏在低端手机上流畅运行

## 阶段四：完整项目与上架（8-12 周）
- **学什么**：从立项到上线完整流程——玩法设计、美术资源整合、测试调优、广告/内购接入、应用商店上架
- **核心知识点**：项目迭代流程、版本管理、变现模式
- **阶段产出**：**一款上架应用商店的游戏**（作品集核心）
- **检验标准**：游戏上线并持续迭代

## 阶段五：就业与进阶
- **就业方向**：Unity 客户端工程师（国内主流）、Unreal 工程师、游戏服务器（Java/Go/C++）
- **进阶**：图形学（渲染管线/Shader）、引擎源码研究
- **面试重点**：C#/C++ 基础、数据结构算法、Unity 核心机制（生命周期/物理/UI）、项目亮点（性能优化经历）
