# 前端开发学习路线

## 路线总览
前端开发负责网页与应用的界面与交互。路线从底层三件套出发，逐步进阶框架、工程化、全栈能力。总周期约 8-12 个月（全职学习 6 个月可就业）。

## 阶段一：Web 基础（4-6 周）
- **学什么**：HTML 语义化标签、CSS 选择器与盒模型、Flex/Grid 布局、响应式、JavaScript 语法与 DOM 操作
- **核心知识点**：盒模型、浮动/定位/Flex 布局差异、JS 事件机制、数组与对象方法
- **阶段产出**：仿写一个静态官网页面（如菜鸟教程首页布局）+ 一个带交互的 Todo 应用
- **检验标准**：不看文档能独立写出页面结构与布局

## 阶段二：JavaScript 进阶（4-6 周）
- **学什么**：ES6+（箭头函数/解构/模块化）、原型链、闭包、this、事件循环、Promise/async、Ajax 与 Fetch
- **核心知识点**：原型继承、作用域链、宏任务微任务、Promise 链与异常处理
- **阶段产出**：用原生 JS 完成一个带接口联调的查询应用（如天气查询）
- **检验标准**：能解释「为什么输出顺序是这样」类面试题

## 阶段三：前端框架（6-8 周）
- **学什么**：Vue 3（国内主流，推荐先学）——模板语法、响应式原理、组件通信、Vue Router、Pinia；React（可选二选一，海外主流）——JSX、Hooks
- **核心知识点**：组件化思想、props/emit/slot、生命周期、路由守卫、状态管理、Composition API
- **阶段产出**：完整的前后端分离管理后台（登录/列表/表单/图表）
- **检验标准**：能用框架独立搭建并完成一个 CRUD 项目

## 阶段四：工程化与进阶（4-8 周）
- **学什么**：Vite/Webpack、Git 协作、TypeScript、Element Plus/Ant Design 组件库、Axios 封装与拦截器、代码规范（ESLint）
- **核心知识点**：构建原理、环境变量、TS 类型系统、组件库二次封装、性能优化（懒加载/防抖节流）
- **阶段产出**：用 Vue3+TS+Element Plus 重构阶段三项目
- **检验标准**：能配置构建工具、写出带完整类型约束的代码

## 阶段五：拓宽与就业（持续）
- **学什么**：Node.js 基础（BFF/服务端渲染）、uni-app 小程序、Next.js/Nuxt、浏览器原理、算法基础
- **就业方向**：Web 前端工程师、小程序工程师、可视化工程师
- **面试重点**：JS 基础（闭包/原型/事件循环）、Vue 响应式与 diff 原理、性能优化、手写 Promise/防抖节流

> 参考来源：菜鸟教程 runoob.com 前端系列教程、Vue/React 官方文档
