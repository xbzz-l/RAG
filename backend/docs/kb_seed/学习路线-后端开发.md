# 后端开发学习路线

## 路线总览
后端开发负责服务器端业务逻辑、数据存储与接口服务。主流语言 Java/Python/Go 三选一，路线以「语言 → 数据库 → 框架 → 进阶」为主线。总周期约 10-14 个月。

## 阶段一：编程语言基础（8-10 周）
- **学什么**：选择主语言——**Java**（企业岗位最多）/ **Python**（上手最快、AI 生态好）/ **Go**（云原生高并发）；语法、面向对象、集合、IO、异常
- **核心知识点**：封装继承多态、泛型、常用类库、Lambda/Stream（Java）或列表推导（Python）
- **阶段产出**：命令行版学生管理系统（纯语言实现增删改查）
- **检验标准**：能独立完成 OOP 设计的小程序

## 阶段二：数据库与 Linux（4-6 周）
- **学什么**：MySQL（SQL 语法、索引、事务、设计范式）、Redis（五种数据类型、缓存场景）、Linux 常用命令与部署
- **核心知识点**：JOIN 查询、索引优化、事务隔离级别、缓存三大问题
- **阶段产出**：为管理系统设计数据库表结构并写清 CRUD 语句；在 Linux 上安装部署 MySQL/Redis
- **检验标准**：能看懂 Explain 执行计划、说出索引失效场景

## 阶段三：后端框架（6-8 周）
- **学什么**：Java 学 Spring Boot（IoC/AOP/MVC/MyBatis-Plus/JPA）；Python 学 FastAPI 或 Django；Go 学 Gin + GORM
- **核心知识点**：分层架构（Controller/Service/Mapper）、参数校验、全局异常处理、拦截器与鉴权
- **阶段产出**：完整的 RESTful API 服务（用户注册登录 + 业务 CRUD + 联调数据库）
- **检验标准**：能用框架搭建规范的项目骨架并部署运行

## 阶段四：中间件与工程化（6-8 周）
- **学什么**：Redis 实战（缓存/分布式锁）、消息队列（Kafka/RabbitMQ 选一）、Git 协作、Docker 容器化、单元测试
- **核心知识点**：缓存一致性、幂等设计、异步解耦、CI/CD 概念
- **阶段产出**：给阶段三项目加缓存、加接口文档、容器化部署
- **检验标准**：项目能在 Docker 中一键启动

## 阶段五：进阶与就业（持续）
- **学什么**：微服务（Spring Cloud Alibaba）、分布式事务、JVM/并发深入、设计模式、系统设计
- **就业方向**：Java 后端工程师、Python 后端工程师、Go 后端工程师
- **面试重点**：MySQL 索引与事务、Redis 缓存三大问题、JVM 与并发（Java 方向）、网络 TCP/HTTP、项目难点表述
