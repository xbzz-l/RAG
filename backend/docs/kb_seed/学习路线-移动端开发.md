# 移动端开发学习路线

## 路线总览
移动端开发包含 Android、iOS 与跨平台三条技术线。新手推荐从**跨平台框架**（Flutter/uni-app）或 Android 原生切入。总周期约 8-12 个月。

## 阶段一：编程与基础（4-6 周）
- **学什么**：一门语言入门——Dart（Flutter 用）/ Kotlin（Android 用）/ JavaScript（uni-app/RN 用）；移动端 UI 基础概念（屏幕适配、dp/pt 单位、布局思想）
- **核心知识点**：语言语法、面向对象、异步编程
- **阶段产出**：语言层面的小练习（控制台应用）
- **检验标准**：语言基础语法与异步机制掌握

## 阶段二：框架入门（8-12 周）
- **学什么（三选一）**：
  - **Flutter（推荐，跨平台份额第一）**：Widget 体系、Stateless/Stateful、布局组件、路由导航、状态管理（Provider/GetX）、网络请求 dio
  - **Android 原生**：Kotlin + Jetpack Compose、四大组件（Activity/Service/BroadcastReceiver/ContentProvider）、生命周期
  - **uni-app**：Vue 语法写小程序/App/H5（前端转移动端最平滑）
- **核心知识点**：组件树/视图树、生命周期、页面导航与传参、状态管理
- **阶段产出**：一个完整的多页面 App（如记事本/天气 App，含网络请求与本地存储）
- **检验标准**：能独立完成 App 从设计到打包运行

## 阶段三：能力深化（6-8 周）
- **学什么**：本地存储（数据库/文件）、推送通知、权限管理、多媒体（相机/相册）、地图与定位、第三方登录、性能优化
- **核心知识点**：异步与线程模型、缓存策略、App 启动优化、内存泄漏排查
- **阶段产出**：给 App 接入推送、定位、图片上传等能力
- **检验标准**：App 具备完整的商用级功能集

## 阶段四：上架与实战（4-6 周）
- **学什么**：应用签名与打包、应用商店上架流程（应用宝/华为/App Store）、热更新/灰度发布、崩溃监控（Bugly/Sentry）
- **核心知识点**：版本管理、隐私合规、应用审核规范
- **阶段产出**：**发布一个真实可下载的 App**（最有说服力的简历项）
- **检验标准**：App 上架并获真实用户反馈

## 阶段五：就业与进阶
- **就业方向**：Flutter 工程师、Android 工程师、iOS 工程师（需 Mac）、小程序工程师
- **面试重点**：生命周期、状态管理方案对比、性能优化实践、一个已上架的项目
- **行业提示**：原生岗位趋于饱和，跨平台（Flutter/RN）+ 小程序能力是加分项
