# 运维与DevOps学习路线

## 路线总览
运维工程师负责保障系统稳定运行；DevOps 强调开发与运维融合、自动化交付。路线从 Linux 出发，逐步进阶容器、云原生与自动化。总周期约 10-14 个月。

## 阶段一：Linux 与网络基础（6-8 周）
- **学什么**：Linux 常用命令、文件权限、Shell 脚本、网络基础（TCP/IP、DNS、HTTP）、vim
- **核心知识点**：文本三剑客（grep/sed/awk）、进程与端口管理、日志分析
- **阶段产出**：独立在 Linux 上部署一个 Web 服务并配置防火墙/域名访问；写一个自动备份脚本
- **检验标准**：脱离图形界面能熟练管理服务器

## 阶段二：常用服务与中间件（4-6 周）
- **学什么**：Nginx（反向代理/负载均衡/HTTPS）、MySQL 部署与主从、Redis 部署与持久化、Tomcat/Java 应用部署、Python 应用部署
- **核心知识点**：location 配置、配置文件与日志排查、备份恢复
- **阶段产出**：搭出一套「Nginx + 应用 + MySQL + Redis」完整服务栈
- **检验标准**：能独立完成整套环境搭建与故障排查

## 阶段三：监控与自动化（6-8 周）
- **学什么**：监控体系（Prometheus + Grafana 指标监控、Zabbix 可选）、日志体系（ELK 或 Loki）、Shell/Python 自动化脚本、Ansible 自动化配置管理
- **核心知识点**：指标采集与告警规则、集中日志检索、批量服务器管理
- **阶段产出**：给服务栈配齐全套监控大盘与告警
- **检验标准**：服务异常时能第一时间收到告警并定位

## 阶段四：容器与云原生（8-12 周）
- **学什么**：Docker（镜像/网络/卷/Compose）、Kubernetes（Pod/Deployment/Service/Ingress/存储）、云平台（阿里云/腾讯云 ECS/SLB/RDS）
- **核心知识点**：容器化改造、K8s 编排与排障（kubectl）、云资源选型
- **阶段产出**：把服务栈全面容器化并运行在 K8s 集群上
- **检验标准**：能用声明式 YAML 管理整套应用

## 阶段五：DevOps 与就业（持续）
- **学什么**：CI/CD（Jenkins 或 GitLab CI）、Git 协作流程、代码扫描、灰度发布
- **就业方向**：Linux 运维工程师、云平台运维、SRE（站点可靠性工程师，薪资更高）、DevOps 工程师
- **面试重点**：Linux 排障思路、Nginx 配置、K8s 核心概念、监控告警体系、一个完整的部署案例

> 参考来源：菜鸟教程 runoob.com 运维系列教程、Kubernetes 官方文档
