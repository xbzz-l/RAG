# JavaScript

## 一、是什么
JavaScript（简称 JS）是 **浏览器原生支持的脚本语言**，也是 Web 前端唯一的编程语言标准（ECMAScript 规范）。定位：网页交互逻辑、前端开发、经 Node.js 扩展后覆盖后端与全栈。

## 二、核心知识
- **基本语法**：变量（let/const）、数据类型（原始类型+对象）、运算符、流程控制、函数
- **对象与原型链**：JS 是原型继承的面向对象语言，对象通过 __proto__ 链式查找属性
- **函数与作用域**：函数是一等公民；var 函数作用域、let/const 块级作用域；闭包是内部函数访问外部变量形成的引用保持
- **异步编程**：事件循环（Event Loop）机制；回调函数 → Promise（then/catch）→ async/await 演进
- **this 指向**：取决于调用方式（普通调用/方法调用/箭头函数/显式绑定 call/apply/bind）
- **ES6+**：箭头函数、解构、模板字符串、展开运算符、模块化（import/export）、class、可选链
- **DOM/BOM**：document 操作页面元素、window 操作浏览器环境；事件模型（捕获/冒泡、事件委托）
- **JSON**：数据交换格式，JSON.parse/stringify

## 三、作用与常用场景
- 网页交互：表单校验、动画、Ajax 请求、DOM 操作
- 前端框架的基石：Vue/React/Angular 均基于 JS（或 TS）
- Node.js 后端开发、命令行工具、桌面应用（Electron）、小程序逻辑层

## 四、基于什么语言/底层原理
- **本身即语言**：ECMAScript 规范定义语法，V8/SpiderMonkey 等引擎编译执行
- **运行环境**：浏览器（含 DOM/BOM API）与 Node.js（含文件/网络模块）
- **执行机制**：单线程 + 事件循环 + 任务队列（宏任务/微任务）；JIT 即时编译

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 全栈通用：一门前端必学、后端可选的语言 | 动态弱类型，大型项目易出隐式类型转换 bug |
| 生态极大：npm 拥有全球最大软件仓库 | 语言历史包袱重（var 提升、==、this 混乱） |
| 异步模型适合 I/O 密集场景 | 单线程 CPU 密集任务性能有限 |
| 上手门槛低，运行环境即浏览器 | 框架更迭快，需持续学习 |

## 六、学习建议
先啃基础语法与 DOM 操作（菜鸟教程 JavaScript 教程体系完整），重点攻克：原型链、闭包、this、事件循环、Promise/async。ES6+ 语法是面试硬通货，务必熟练。
