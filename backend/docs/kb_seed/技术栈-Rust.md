# Rust

## 一、是什么
Rust 是 **Mozilla 主导开发、2015 年发布的系统级编程语言**。定位：在不使用垃圾回收（GC）的前提下保证内存安全与线程安全，性能对标 C/C++。连续多年蝉联 Stack Overflow 最受喜爱语言。

## 二、核心知识
- **所有权（Ownership）**：Rust 灵魂机制——每个值有唯一所有者；离开作用域自动释放；移动语义（赋值默认转移所有权）
- **借用与生命周期**：引用（&）借用不转移所有权；同一时刻只能有一个可变引用或多个不可变引用；生命周期标注保证引用有效性
- **内存安全**：编译期排除悬垂指针、双重释放、数据竞争（无需 GC 与手工 free）
- **枚举与模式匹配**：Option<T>/Result<T, E> 代替 null 与异常；match 穷尽匹配
- **trait**：类似接口，定义共享行为；trait bound 泛型约束；Send/Sync 标记线程安全
- **错误处理**：Result 显式传播，? 操作符简化；panic 用于不可恢复错误
- **智能指针**：Box（堆分配）、Rc/Arc（引用计数，Arc 线程安全）、RefCell（内部可变性）
- **并发**：线程 spawn、消息通道 channel、Mutex/Arc 组合；编译器保证数据竞争不存在
- **包管理**：Cargo（构建/依赖/测试一体）、crates.io 生态

## 三、作用与常用场景
- 系统编程：操作系统、嵌入式、驱动
- 高性能基础设施：数据库（TiKV）、浏览器引擎（Firefox Servo）、区块链
- WebAssembly 与 Web 服务端（Actix-Web/axum 性能顶尖）
- CLI 工具（ripgrep/fd 等）

## 四、基于什么语言/底层原理
- **编译型**：LLVM 后端生成机器码；无 GC 无运行时，性能与 C++ 同级
- **内存安全原理**：所有权+借用检查器在编译期静态分析所有内存操作；零成本抽象（trait/迭代器等运行时无开销）

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 内存安全 + 线程安全 + 高性能兼得 | 学习曲线极陡（所有权/生命周期劝退率高） |
| 无 GC 无运行时开销 | 编译速度慢 |
| 现代语言特性（模式匹配/包管理/工具链） | 生态年轻，招聘岗位相对少 |
| 编译器错误信息友好 | 开发速度慢于脚本语言（适合底层而非快速迭代业务） |

## 六、学习建议
适合有 C/C++ 或扎实编程基础者。路径：官方《Rust 程序设计语言》+ rustlings 练习题 → 死磕所有权/借用/生命周期 → 错误处理与 trait → 用 Rust 写一个 CLI 工具实战。业务应用层学习性价比低，系统/基础设施方向价值极高。
