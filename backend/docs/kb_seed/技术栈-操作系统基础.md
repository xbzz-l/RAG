# 操作系统基础

## 一、是什么
操作系统（OS）是 **管理计算机硬件与软件资源的系统软件**，是应用程序与硬件之间的桥梁。定位：进程/内存/文件/设备的管理者，Linux/Windows/macOS 都是操作系统。

## 二、核心知识
- **进程与线程**：进程是资源分配单位，线程是 CPU 调度单位；进程状态（就绪/运行/阻塞）；上下文切换开销
- **进程间通信（IPC）**：管道、消息队列、共享内存、信号、Socket
- **线程同步**：互斥锁、信号量、条件变量；死锁四条件（互斥/持有并等待/不可剥夺/循环等待）与银行家算法
- **内存管理**：虚拟内存（逻辑地址→物理地址）、分页与页表、缺页中断、页面置换算法（LRU/FIFO）、分段
- **文件系统**：inode、目录结构、文件描述符
- **CPU 调度**：调度算法（先来先服务/短作业优先/时间片轮转/优先级）、用户态与内核态切换（系统调用）
- **I/O 模型**：阻塞/非阻塞、IO 多路复用（select/poll/epoll）、零拷贝——理解 Nginx/Redis/Node 高性能的钥匙
- **中断与系统调用**：用户程序请求内核服务的唯一合法入口

## 三、作用与常用场景
- 理解程序如何真正运行（内存/CPU/磁盘视角）
- 高并发服务优化（IO 模型选择、锁竞争分析）
- 排查线上疑难问题（内存泄漏、CPU 飙高、僵尸进程）
- 后端/基础架构岗位面试重点

## 四、基于什么语言/底层原理
- **实现语言**：C/汇编为主；内核运行在特权态（内核态），用户程序在用户态，系统调用是唯一交互通道
- **核心机制**：时钟中断驱动调度、MMU 硬件完成地址转换、中断机制驱动 I/O

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 计算机体系知识的枢纽 | 理论性强，与日常业务开发关联间接 |
| 面试硬通货（大厂必考） | 知识点多且深，需长期消化 |
| 性能优化与问题排查的底层依据 | 纯看书易忘，需结合 Linux 实操 |

## 六、学习建议
路线：进程线程 → 内存管理与虚拟内存 → 文件系统 → IO 模型（重点，结合 Nginx/Redis 案例）→ 死锁与同步。配合 Linux 实操（top/ps 观察进程、写多线程程序验证锁）效果最好。经典教材：《现代操作系统》《深入理解计算机系统》（CSAPP）。
