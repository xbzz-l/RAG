# 计算机网络基础

## 一、是什么
计算机网络是 **连接多台计算机实现资源共享与通信的系统**，Internet 是全球最大的网络。该学科研究数据如何在网络中传输，是后端/运维/安全岗位的底层必修课。

## 二、核心知识
- **分层模型**：OSI 七层（应用/表示/会话/传输/网络/链路/物理）与 TCP/IP 四层（应用/传输/网络/网络接口）；分层思想：每层独立职责、对等层通信
- **应用层**：HTTP/HTTPS、DNS（域名解析，递归+迭代查询）、FTP、SMTP
- **传输层**：TCP（可靠、面向连接：三次握手四次挥手、滑动窗口、拥塞控制、流量控制）与 UDP（无连接、快、不可靠，适用视频/游戏/DNS）
- **网络层**：IP 地址与子网掩码、路由与转发、ARP（IP→MAC）、ICMP（ping/traceroute）
- **数据链路层**：MAC 地址、以太网帧
- **HTTP 核心**：请求/响应结构（报文头/状态码 200/301/304/401/403/404/500）、GET/POST/PUT/DELETE、Cookie/Session/Token、HTTP 1.1 与 2.0 差异（多路复用/头部压缩）、HTTPS（TLS 加密）
- **经典面试题**：浏览器输入 URL 到页面展示的完整过程；三次握手为什么是三次；TCP 粘包拆包；TIME_WAIT 状态

## 三、作用与常用场景
- 理解一切网络应用（Web/IM/直播）的通信原理
- 排查线上问题（连不上/慢/丢包）
- 后端接口设计、负载均衡、安全攻防的底层支撑
- 面试必考（后端/运维/安全岗位）

## 四、基于什么语言/底层原理
- **本质**：分层封装——数据自上层向下层层加头部（封装），接收方层层拆解（解封装）；路由协议（OSPF/BGP）与传输协议共同完成端到端通信

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 计算机基础核心，一通百通 | 概念抽象，协议细节多 |
| 学习资源极丰富（谢希仁教材/图解系列） | 与实际开发关联需主动思考 |
| 就业刚需知识 | 纯理论枯燥，需结合抓包实践 |

## 六、学习建议
路线：分层模型 → HTTP（重点，配合浏览器 F12 抓包）→ TCP/UDP（重点，配合 Wireshark 观察握手）→ IP/DNS → 用"URL 到页面"经典题串联全部知识。菜鸟教程与《图解 HTTP》《图解 TCP/IP》适合入门。
