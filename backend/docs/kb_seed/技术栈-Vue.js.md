# Vue.js

## 一、是什么
Vue.js 是一款**渐进式 JavaScript 前端框架**，由尤雨溪于 2014 年发布。核心定位：用于构建用户界面，只关注视图层，可渐进式集成（既可只当模板引擎用，也可配合全家桶做完整单页应用）。当前主流大版本为 Vue 3。

## 二、核心知识
- **响应式系统**：基于 ES6 Proxy 追踪数据变化，数据变更自动触发视图更新，开发者无需手动操作 DOM
- **模板语法**：插值表达式 `{{ }}`、指令（v-if/v-for/v-bind/v-model/v-on）声明式描述界面
- **虚拟 DOM**：用 JS 对象描述 DOM 结构，diff 算法对比新旧差异后最小化更新真实 DOM
- **组件化**：单文件组件（SFC，.vue 文件）封装模板+逻辑+样式，props 传参、emit 事件、slot 插槽
- **Composition API**：Vue 3 核心写法，setup 语法糖组织逻辑，比 Options API 更利于逻辑复用
- **生命周期**：onMounted/onUpdated/onUnmounted 等钩子控制组件各阶段行为
- **生态**：Vue Router（路由）、Pinia（状态管理）、Vite（构建工具）、Element Plus（UI组件库）

## 三、作用与常用场景
- 单页应用（SPA）：管理后台、电商前台、门户网站
- 渐进式改造：老项目（如 jQuery 多页应用）局部引入，逐步替换
- 中小团队首选：上手曲线比 React/Angular 平缓，模板语法贴近原生 HTML
- 移动端：搭配 uni-app 可一套代码编译小程序/App/H5

## 四、基于什么语言/底层原理
- **开发语言**：JavaScript（推荐配合 TypeScript 做类型约束）
- **底层实现**：响应式系统基于 Proxy 劫持对象读写；渲染函数编译模板为 VNode；diff 算法做新旧 VNode 比对；编译器+运行时分离设计

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 上手简单，中文文档完善，学习曲线平缓 | 大型项目代码组织约束弱于 Angular（灵活即随意） |
| 渐进式：轻量引入、按需扩展 | 生态早期碎片化（插件质量参差，Vue 2→3 迁移成本） |
| 响应式开发体验好，模板直观 | 高端岗位需求占比低于 React（国内反之） |
| 性能优秀：Vue 3 较 Vue 2 渲染性能显著提升 | 复杂状态管理场景需 Pinia 等额外方案 |

## 六、学习建议
先掌握 JavaScript 基础（ES6+），再学模板语法 → 响应式原理 → 组件通信 → 路由与状态管理 → 实战项目；配合 Vue 官方文档与菜鸟教程 Vue3 教程系统性学习。
