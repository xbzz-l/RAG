# 网络安全学习路线

## 路线总览
网络安全分**攻（渗透测试/红队）**与**防（安全运维/蓝队）**，两方向共用基础。总周期约 12-18 个月，需要持续实战。**红线提醒：只在授权环境（靶场/CTF）练习**。

## 阶段一：基础底座（8-10 周）
- **学什么**：网络基础（TCP/IP、HTTP 协议细节、DNS）、Linux 系统与命令、一门脚本语言（Python 首选）、Web 基础（前端/后端工作原理）
- **核心知识点**：三次握手、HTTP 请求响应结构、Linux 权限与文件系统、Python 写简单工具
- **阶段产出**：能搭建本地实验环境（虚拟机/Kali + 靶场）
- **检验标准**：理解 Web 应用完整请求链路

## 阶段二：Web 安全核心（10-14 周）
- **学什么**：OWASP Top 10 漏洞原理与利用——SQL 注入（联合/盲注）、XSS（反射/存储/DOM）、CSRF、文件上传、命令注入、越权、SSRF、反序列化
- **核心知识点**：每个漏洞的成因、利用条件、手工验证方法、修复方案
- **阶段产出**：在 DVWA/Pikachu 靶场逐个漏洞完成「发现→利用→修复」实验
- **检验标准**：能手工发现并利用常见 Web 漏洞

## 阶段三：渗透工具与流程（8-12 周）
- **学什么**：信息收集（子域名/端口/指纹）、Nmap 扫描、Burp Suite 抓包与改包、SQLMap、Metasploit 基础、提权思路
- **核心知识点**：渗透测试标准流程（PTES）、工具背后的原理（不只会点按钮）
- **阶段产出**：对授权靶场完成 2-3 次完整渗透并输出报告
- **检验标准**：能独立走通「信息收集→打点→提权→报告」流程

## 阶段四：专项深化（按方向选，10-14 周）
- **红队方向**：内网渗透（横向移动/域渗透）、免杀基础、钓鱼演练
- **蓝队方向**：安全加固（基线配置）、WAF/IDS 部署、日志分析与应急响应、威胁情报
- **代码审计方向**：读源码找漏洞（PHP/Java 审计），安全开发
- **阶段产出**：方向对应的专项实战成果
- **检验标准**：具备独立完成专项任务的能力

## 阶段五：就业与进阶
- **就业方向**：渗透测试工程师、安全运维工程师、安全开发、等级保护测评
- **进阶**：CTF 竞赛持续刷题（BUUCTF 等平台）、考取 CISP/NISP 证书
- **面试重点**：OWASP 漏洞原理（必考）、渗透流程表述、一个完整渗透案例、防御思维（攻防一体）
- **再次强调**：未授权测试违法；学习全程使用靶场与 CTF 环境

> 参考来源：菜鸟教程 runoob.com、OWASP 官方文档
