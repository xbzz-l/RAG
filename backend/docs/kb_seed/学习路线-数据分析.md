# 数据分析学习路线

## 路线总览
数据分析师从数据中发现业务规律、支撑决策。核心技能栈：SQL + Excel + Python + 可视化 + 业务思维。总周期约 6-10 个月，转行友好度高。

## 阶段一：工具基础（4-6 周）
- **学什么**：Excel 进阶（透视表/VLOOKUP/图表）、SQL（MySQL 查询）
- **核心知识点**：聚合函数与 GROUP BY、多表 JOIN、窗口函数（面试高频）、透视分析
- **阶段产出**：用 SQL 完成一套业务取数需求（如各品类销售额统计）
- **检验标准**：拿到业务问题能独立写出取数 SQL

## 阶段二：Python 数据分析（6-8 周）
- **学什么**：Python 语法基础、NumPy（数组计算）、pandas（核心：DataFrame 清洗/分组/透视）、Matplotlib 绘图
- **核心知识点**：缺失值/重复值/异常值处理、groupby 聚合、数据合并、时间序列处理
- **阶段产出**：用 pandas 完成一个公开数据集的完整清洗分析
- **检验标准**：能独立完成「数据清洗→分析→出图」全流程

## 阶段三：可视化与报表（4-6 周）
- **学什么**：Power BI 或 Tableau 或 FineBI（选一精通）、可视化设计原则、图表选型
- **核心知识点**：仪表盘搭建、钻取与联动、数据看板设计
- **阶段产出**：为一家虚构公司搭建业务监控看板（销售/用户/库存）
- **检验标准**：看板能直接用于业务汇报

## 阶段四：统计学与业务思维（6-8 周）
- **学什么**：描述统计（均值/方差/分布）、推断统计（假设检验/置信区间）、AB 测试、常用分析模型（漏斗分析/留存分析/RFM 模型/帕累托分析）
- **核心知识点**：P 值理解、AB 测试流程与样本量、指标体系搭建（北极星指标）
- **阶段产出**：一份完整的行业分析报告（如某品类电商销售分析）
- **检验标准**：能独立完成「业务问题 → 指标体系 → 分析结论」闭环

## 阶段五：进阶与就业
- **进阶方向**：机器学习基础（sklearn 入门）、大数据工具（Hive SQL/Spark SQL，进大厂必备）
- **就业方向**：数据分析师、商业分析师、数据运营
- **面试重点**：SQL 手写题（必考）、AB 测试、指标体系设计、一个能讲清楚分析思路的项目
