# 网络安全

## 一、是什么
网络安全是 **保护网络系统、数据与设备免受攻击、破坏和未授权访问的学科与工程领域**。定位：信息安全的网络层面，涵盖攻击技术（渗透测试）与防御技术（安全运维）两大方向。

## 二、核心知识
- **Web 安全（OWASP Top 10）**：SQL 注入（参数化查询防御）、XSS 跨站脚本（输出编码/CSP）、CSRF 跨站请求伪造（Token 校验）、文件上传漏洞、越权访问（水平/垂直越权）、SSRF、反序列化漏洞
- **网络协议安全**：TCP/IP 协议栈、三次握手、常见端口与服务（80/443/22/3306/6379）、抓包分析（Wireshark/tcpdump）
- **渗透测试流程**：信息收集 → 漏洞扫描 → 漏洞利用 → 权限提升 → 痕迹清理 → 报告编写；常用工具：Nmap、Burp Suite、Metasploit、SQLMap
- **密码学基础**：对称加密（AES）、非对称加密（RSA）、哈希（MD5/SHA，加盐存储密码）、HTTPS/TLS 握手、数字证书与签名
- **系统安全**：Linux 权限与加固、提权原理、恶意代码分析基础
- **安全运维**：防火墙（iptables/安全组）、WAF、IDS/IPS 入侵检测、日志审计、应急响应
- **法律红线**：仅可在授权范围内测试（靶场/CTF/授权渗透），未授权入侵属违法行为

## 三、作用与常用场景
- 渗透测试工程师：授权安全评估
- 安全运维/蓝队：防护、监控、应急
- 安全开发：在编码阶段消除漏洞（SDL 安全开发生命周期）
- CTF 竞赛：技能训练与选拔

## 四、基于什么语言/底层原理
- **开发语言**：Python（工具编写首选）、C（底层/二进制安全）、JavaScript（前端攻击面）、Shell
- **底层原理**：攻击本质是利用协议/程序设计的缺陷；防御本质是纵深防御（多层防护）+ 最小权限原则

## 五、优缺点
| 优点 | 缺点 |
| --- | --- |
| 行业刚需，安全人才缺口大 | 知识面极广，学习周期长 |
| 技术护城河深，越老越吃香 | 方向碎片化（Web/二进制/内网/取证） |
| 攻防思维反哺开发能力 | 部分技术敏感，需守法合规 |
| CTF 等实战资源丰富 | 夜间应急/值守岗位辛苦 |

## 六、学习建议
路径：网络与 Linux 基础 → Web 漏洞原理与靶场实战（DVWA/Pikachu）→ 工具链（Burp/Nmap）→ 渗透流程实践 → 纵深防御与加固。建议以白帽子（防御+授权测试）心态学习，在靶场/CTF 平台（BUUCTF 等）练习，绝不触碰未授权目标。
